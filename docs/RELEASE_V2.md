# SHUBO RUN v2.0 — FEVER EDITION

2026-09-12。ユーザーの「この方向で全力で楽しく作り切る。改善・検証・公開まで一任」に基づくリリース。

## 遊びの改善

- 盤面スワイプと44px以上の方向ボタン。曲がれない方向を次の角まで予約し、予約中の矢印を表示。
- iPhone縦持ちのプレイ中は盤面・操作を画面内に固定。Safariの可変ビューポート、safe area、画面回転による停止を考慮。
- 糖/大粒10連鎖で4秒フィーバー。採取点×2・接触無効。発動中は再充填/延長せず、連鎖切れや接触で充填をリセット。
- 次ステージの支援選択：6秒保護、エネルギー満タン、時間+12秒。ミッションと短い3ステージは保持。
- 日本時間の日替わり迷路。全通路の接続と必要な糖数を保証。定番260907は元の道を保持。
- オプションのWebAudio合成音。初期OFF、音ONは利用者のタップで開始。採取・スキル・接触・クリアの音を区別、非表示/ポーズで停止。
- 自己ベスト更新を結果画面で表示。旧記録を保持し、日替わりと音は別の設定保存。
- 保護/スタン解除時に両者が停止している接触も正しく判定。スキルの回復待ち/不足エネルギーを表示。

## 確認

- lint / TypeScript / unit / build：成功。単体25件。
- 50シード×3環境×3ステージで迷路接続、採取可能数、ランドマーク、競合初期位置を検証。
- Chromium：既存の18操作シナリオ＋新しいタッチ/保存/回転9シナリオ、計27件すべて成功（失敗0・skip0、2.1分）。公開前のCI結果はGitHub Actionsを参照。
- デスクトップWebKit：390×844、320×568。実時間のタッチ開始/移動/停止/ダッシュ、ポーズ中の時間固定、手動再開、音/日替わり設定保持、通常のゲーム更新を時計で進めて敗北/再戦。2画面とも成功、JS/consoleエラー0。
- 新しい小画面検証は320×568と390×664も対象。方向とスキルの各タッチ領域44px以上、全盤面と操作部が画面内、盤面が正方形、スワイプによる意図しないスクロールなし。
- 勝利状態の注入、無敵の試験用ボタン、敵の消去などでプレイ検証を代用していない。

## 実行方法

READMEの標準検証に加え、WebKitの確認：

```sh
npx playwright install --with-deps webkit
npm run build
npm run preview
# 別ターミナル
node scripts/verify-webkit.mjs
# 公開ページを対象にする場合
node scripts/verify-webkit.mjs https://toraikura.github.io/shubo-run/
```

WebKitの機械記録と画像は `test-results/webkit-smoke/`（ignored）。Chromiumは `playwright-report/`。画面証拠をdocs/screenshotsにも保存。

## 未検証と境界

実機iPhone Safari、実際の着信/OSスリープ、ユーザーによる音の聴取、低性能実機の長時間負荷、第三者の面白さ評価は未検証。WebKitはSafariと同系統のエンジンを使ったデスクトップのエミュレーションであり、iPhone実機試験ではない。

科学説明は従来の出典付き説明を保持。フィーバー、支援、酸性化、温度係数、迷路、音は架空のゲーム表現。醸造の安全性・酒質の判断には使えない。

広告・課金・会員・通信型ランキング・分析SDKは追加していない。SAKE CLASHと親サイトは変更していない。GitHubのv1.0.0を保持し、変更は専用PRとv2.0.0で追跡する。
