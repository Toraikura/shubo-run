## ブラウザマトリクス

1440×1000（PC）、360×800（タッチエミュレーション）、390×844（タッチエミュレーション）の各画面で次を実行し、すべて成功しました。

1. 低め：開始 → 移動／採取 → ポーズ／再開 → 3ステージクリア → 同じコースへ再挑戦 → リロード後の記録。
2. 中間：同上。プレイ前・プレイ中のスクリーンショットも保存。
3. 高め：同上。競合接近時は見えているパルスボタンまたはJで停止させて攻略。
4. ダッシュ → 放置による失敗 → 再挑戦 → blur / visibilitychange / 画面外の自動ポーズ → 科学ノート。
5. reduced motion → 破損localStorageから復旧 → ポーズから終了 → 別コース選択 → キーボードフォーカス復帰。
6. 時計をモックしない実時間テスト：開始 → キー／タッチで移動 → 停止 → 敵接触による失敗 → 再挑戦 → ポーズ。

攻略テストはSVGに描かれている壁・糖・競合・自分の位置を読み、実際のキーボード・タッチイベントを発生させます。ゲーム内部状態への書き込み、無敵付与、敵消去、ゴールフラグの注入はしません。シードは既定値260907。別シードの決定性と境界は単体テストで確認しています。

1〜5はブラウザ時計を明示停止してから固定時間ずつ進め、入力の再現性を保ちます。6は通常のrequestAnimationFrameと実経過時間です。全画面幅で、各温度のハイスコア保存／リロード保持、横スクロールなし、実行中の未捕捉例外なし、ゲーム中の別オリジン通信なしを確認しました。

visibilitychange / blurは実ブラウザ内でイベントとdocument.hiddenを明示設定してハンドラーを検証。画面外停止は科学ノートを展開して実際にスクロールし、盤面を完全に画面外に置いて検証します。OSのスリープ復帰や実機のアプリ切替を網羅した試験ではありません。

## 検出と修正

- 初期のPC表示では盤面と操作ボタンを一度に見にくかったため、盤面幅とPC操作部を縮め、開始時にゲーム全体へスクロールする配置に変更。360pxでも開始後はスコア・全盤面・方向ボタン・スキルが同時に見えます。
- 初期の画面外テストは、ページ最下部へ移動してもPCでは盤面が一部見えていました。科学ノートを展開して十分にスクロールできる条件に修正。ゲームの「盤面が完全に画面外で停止」という仕様は保持。
- テスト時計をinstallするだけで自然経過も残る状態から、pauseAtによる明示停止とrunForによる制御へ統一。入力待ち中に状態が先へ進む揺らぎを除去。
- 親のPlaywrightを実行中に子の独立依存を作ると2つの実体を参照するため、依存導入を完了させ、子のCLIだけで全件を再実行。
- SVGのimage roleとゲーム操作領域のフォーカスは意図的なアクセシビリティ実装。該当する2種類のlint判定だけをソース内の説明付き局所除外で扱っています。

## 実装の境界と未検証

- NOT TESTED：実機iPhone / iPad Safari、Android実機、Safari / Firefox、各スクリーンリーダー、OSスリープ後の復帰、低性能端末での長時間負荷。
- NOT TESTED：第三者プレイヤーによる面白さ・難易度評価。全温度にクリア経路があることと操作ループは検証済みですが、万人向けの難易度保証ではありません。
- 科学監修者によるレビューは未実施。科学説明はREADMEの一次資料を確認し、ゲーム挙動から実際の醸造について推論しない構造です。
- 科学ノートの外部リンクはクリックによる遷移先。自動通信、分析SDK、会員機能、課金、外部DBはソースにありません。
- 元サイト・iframe・公開サブパスへの接続は未実施。統合時は別途その配信環境でE2Eが必要です。
- ローカルのハイスコアはユーザーによる編集を防止しません。端末／ブラウザ／オリジンを変えると別の記録になります。
